# 震惊诗

## 触发

用户说 **写一首震惊所有人的诗**，或明确要求「震撼」「惊艳」「让人忘不了」的诗时，执行本技能。

## 流程

1. **定锚**（缺则问一句，勿连环追问）  
   - 主题/意象（可抽象：时间、城市、离别、科技、哲学等）  
   - 体裁：现代自由诗 / 七言绝句 / 五言 / 词牌（用户指定则服从）  
   - 语气：冷峻 / 炽烈 / 荒诞 / 悲悯（默认：冷峻 + 一击）

2. **写前约束**（内化，勿向用户罗列理论）  
   - 至少一处 **反常识意象** 或 **语义急转**（第二段或末句）  
   - 至少一处 **具体可感** 的细节（物、声、触感），禁空洞口号  
   - 禁烂喻：流星、烟火、沧海桑田、心如刀绞、泪如雨下等，除非彻底翻新用法  
   - 篇幅：现代诗 8–16 行；绝句严格四句；不必解释寓意

3. **技法池**（择 2–3 项，勿全堆）  
   - 末句落点：把宏大命题压进极小物象  
   - 人称突变：你/我/它/我们 在段间换位  
   - 节奏断裂：长句后接极短句（三字以内）  
   - 科学/日常并置：公式、公交、验证码与古典意象同框  
   - 留白：最后一句不闭合，让读者补完

4. **输出格式**

```markdown
## [自拟标题]

[正文]

---
*一声*：[用一句话点出震撼点，≤20 字，可选；用户只要诗则可省略]
```

5. **自检**（通过再交付）  
   - [ ] 读毕有「顿一下」的瞬间，而非仅辞藻华丽  
   - [ ] 删掉任意一句仍损失力度 → 每句有负重  
   - [ ] 无说教、无「我们要」「愿天下」式收束

## 用户原文（技能使命）

> 写一首震惊所有人的诗
