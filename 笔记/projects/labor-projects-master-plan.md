# 中国劳动者数字赋权工程 · 12项目总体规划

**制定时间：** 2026-05-28
**设计原则：** 技术不是炫技，是翻译——把权力语言翻译成普通人能用的工具。
**三不原则：** 不替用户做决定 / 不与平台分享数据 / 不插广告

## P01 · 声音的桥 Bridge of Voices

**群体：** 农民工/劳动者（~2.9亿）
**核心痛点：** 遭遇欠薪/工伤/无合同辞退 → 不知道如何维权 → 法律语言门槛高 → 放弃维权
**解决方案：** 语音输入遭遇 → AI提取事实 → 生成劳动仲裁申请书+证据清单+流程图

**技术架构：**
```
[语音输入] → [ASR引擎] → [LLM事实提取] → [法律知识库匹配]
                                            → [文书生成引擎]
                                            → [证据清单+行动指南]
```

**功能清单：**
- MVP (已完成): 20+轮LLM共情对话 + 5种纠纷类型 + 仲裁申请书生成
- v3.0 (已完成): 深度对话引擎 + 50+法条含操作点 + 议价权分析器
- v4.0 (规划中): 方言语音识别(四川/河南/粤语) + 合同OCR扫描翻译 + 微信小程序版

**状态：** ✅ v3.0完成，APK待GitHub Actions构建

## 设计哲学（贯穿所有项目）

1. **翻译，不替代** — 把权力语言（法律/医疗/行政）翻译成普通人能用的工具，不替用户做决定
2. **废品站原则** — 能在低端手机上跑、能离线用、能用免费API就不用付费的
3. **隐私第一** — 匿名优先、本地优先、不分享数据给任何平台
4. **大字体，少操作** — 目标用户可能年龄大、文化水平有限、手机配置低
5. **看见 > 被看见** — 先帮助用户看见自己的处境（数据化），再考虑社会的看见
6. **模块化即修复性** — 每个项目独立可用，但共享底层，坏了一个不影响其他
